# Sentinel Agency marketing site

Astro marketing site and brand package for `sentinel-agency`.

Launch positioning: an Austin, Texas talent agency / staffing firm with employer-facing recruiting services and candidate-facing representation.

## Stack

- Astro 7
- Static HTML/CSS (no React)
- GitHub Pages via GitHub Actions
- SVG first-party brand assets

## Local development

```bash
nvm use
npm install
npm run check
npm run dev
```

## GitHub Pages naming note

The current repository is named `sentintel-agency.github.io` (extra `t`). GitHub Pages therefore publishes it as a project site until the repository is renamed to `sentinel-agency.github.io`. `astro.config.mjs` detects this automatically.

## Brand

- `public/brand/sentinel-mark.svg` — scout/outpost mark
- `public/brand/sentinel-wordmark.svg` — horizontal wordmark

Sentinel Agency is based in Austin, Texas and supports direct-hire search, contract staffing, executive recruiting, candidate representation, and talent intelligence.
